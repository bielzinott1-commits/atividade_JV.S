Variáveis

Variáveis armazenam informações que podem ser utilizadas durante a execução do programa. 

let nome = "Davi";

console.log(nome);
console.log(idade);

let

Use quando o valor poderá ser alterado. 

let contador = 0;

contador = 1;
contador = 2;

const

Use quando a variável não receberá uma nova atribuição. 

const nome = "Davi";

Aula 05

if, else e else if

Condicionais permitem que o programa tome decisões. 

const idade = 18;

if (idade >= 18) {

    console.log("Maior de idade");

} else {

    console.log("Menor de idade");

}

Exemplo

const nota = 8;

if (nota >= 9) {

    console.log("Excelente");

} else if (nota >= 7) {

    console.log("Bom");

} else {

    console.log("Precisa estudar");

}
Aula 06

Switch

O switch é útil quando temos várias opções baseadas no mesmo valor. 

const dia = 2;

switch (dia) {

    case 1:
        console.log("Segunda");
        break;

    case 2:
        console.log("Terça");
        break;

    default:
        console.log("Outro dia");

}
Aula 07

Loops

for

for (let i = 0; i < 5; i++) {

    console.log(i);

}

while

let contador = 0;

while (contador < 5) {

    console.log(contador);

    contador++;

}

do while

let numero = 0;

do {

    console.log(numero);

    numero++;

} while (numero < 5);

Rest Operator

    return numeros.reduce(
        (total, numero) => total + numero,
        0
    );

}

);
